Interest & Principal Predictor

Welcome to the, "Interest & Principal Predictor," This is a simple, easy-to-use web app that helps you see how your money grows over time. Whether you are saving up, learning about personal finance, or just curious about how compound interest works, this tool will help you see the growth of any amount of money over any amount of time.

1- What Does It Do?

This app calculates how much interest your money will earn (or has earned) based on simple information you provide.

The web app's two main modes:
1. **Standard Mode**: You know your starting amount (principal), and you want to see how much interest it will generate.
2. **Forgot Principal Mode**: You only know your *current* total balance, and you want the app to work backward to figure out how much you originally started with.

2- Features

- Predictions: Predict what your money was worth in the past and what it will be worth in the future.
- Crossover Notifications: The app will automatically notify you with a message when your earned interest finally matches or exceeds your original starting amount!
- Visual Charts & Tables: Your results are shown in a clean, easy-to-read table and a simple line graph.
- Calendar Year Tracking: Instead of just showing "Year 1, Year 2," it shows you the actual calendar year (like 2026, 2027) so it makes real-world sense.

3- How to Run It on Your Computer

No Need for programming! Just follow these instructions:

1. Install Python: Make sure you have Python installed on your computer. (You can download it for free at [python.org](https://www.python.org/)).
2. Open your terminal or command prompt:

3. **Install the required tools** by typing this command and pressing Enter:
   [pip install streamlit pandas]

4. **Run the app**: Navigate to the folder where you saved this project and type:
   [streamlit run 'app.py']

   *(Note: If your file is named something else, replace the 'app' in 'app.py' with your file name).*
5. A new tab will automatically open in your web browser with the app ready to use!

4- Tools Used

- Python The main programming language that makes the math work. With multiple useful functions for different uses like sorting lists and predicting values.
- Streamlit: A tool that turns Python scripts into beautiful, interactive web pages without needing to know complex web development. with session state was used to save and share variables across different script reruns for each user's browser tab
- Pandas: A library that helps organize the data into neat tables.
